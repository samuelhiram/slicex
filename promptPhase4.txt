## Tu tarea: BLOQUE 4

### Objetivo
Conectar calculateBalanceAt al canvas via la store de Zustand,
de forma que cuando el playhead se mueva, el balance se recalcule
y esté disponible para que React lo muestre.

### Implementación exacta

1. packages/canvas/src/adapters/store-subscriber.ts
   - Subscribirse a editorStore de Zustand
   - Cuando playheadAt cambie: llamar calculateBalanceAt(activeTimeline, playheadDate)
   - Resultado disponible via callback onBalanceChange(balance: number)
   - Si no hay activeTimeline: onBalanceChange(0)
   - Cleanup: desuscribirse en destroy()

2. Verificar compatibilidad de tipos entre:
   - El modelo de TimelineDocument en @slicex/core/src/types.ts
   - El modelo que editorStore guarda en su campo document
   - Si hay mismatch de tipos: ajustar el tipo en editorStore
     para que sea compatible con lo que calculateBalanceAt espera
   - NO cambiar la firma de calculateBalanceAt, solo los tipos del store

3. packages/canvas/src/index.ts
   - Exportar el tipo del callback: BalanceChangeCallback

4. Test obligatorio en packages/canvas/tests/:
   - balance-calculation.spec.ts
   - Verifica que store-subscriber llama onBalanceChange con el valor correcto
   - Usa modo headless (sin DOM)
   - Al menos 3 casos:
     a) playhead antes de cualquier objeto → balance = valor inicial
     b) playhead después de un ingreso → balance aumenta
     c) playhead después de un egreso → balance disminuye
